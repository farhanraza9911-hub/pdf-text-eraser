How to get a GitHub token (one time)
  1. github.com → your photo → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name: pdf-eraser-admin. Expiration: up to 1 year.
  3. Repository access: Only select repositories → pdf-text-eraser.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, copy it and paste it here. Keep it secret.
